# Prompt Smart Sales Funnel

Static sales page for Prompt Smart — The Everyday AI Playbook.

## Deploy to Render
1. Create a GitHub repository and add these files.
2. In Render, create a new Static Site from the repository.
3. Build command: leave blank.
4. Publish directory: `.`
5. Deploy.
6. Add custom domain: `promptsmart.everydayanalysthub.com`.
7. In your DNS provider, create the CNAME value Render provides.
